# Documentation assets

This folder holds the media referenced from the root [README](../README.md).

- `images/` — screenshots and GIFs (`project-t11g10-1.png` … `project-t11g10-5.png`, `project-t11g10-4.gif`).
- `videos/` — the full demo recording (`project-t11g10.mp4`).

The binary media is **not** committed to keep the repository lightweight; drop the
files in the directories above (matching the names linked from the README) to make
the previews resolve locally.
